겅이마켓 원정대 2단계 패치 (2026-11-09)
기존 패치 전부 적용한 상태에서 압축 내부 상대경로 그대로 덮어쓰세요.

- 토벌장 우측 상단 '스테이지 클리어 시' 문구
- 원정대 보스 HP 아래 '1단계/2단계' 표시
- 1단계 4,000,000 HP 처치 후 같은 참여자 배치 유지, 2단계 10,000,000 HP 자동 시작
- 1단계 300골드/30파편, 2단계 500골드/50파편 (각 단계 중복 지급 방지, 우편함 수령)
- 보스 토벌 완료 문구 제거
- test 계정 전용 보스 HP 100 및 현재 단계 보스 재생성 버튼 (TEST_SERVER=true)
- 2단계 종료 후 보스는 남은 시간 동안 처치 상태, test 계정은 재생성 가능
주의: 실제 DB 연동 테스트/전체 TypeScript 빌드는 미실시. DB 백업 후 테스트 서버에서 적용.
