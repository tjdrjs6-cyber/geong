겅이마켓 2.1 수정 패치 — 2.0 적용 후 덮어쓰기
1. 제초장: 서버의 펫 +30% 정산 수식은 기존에 존재. 클라이언트 분당 예상 코인에서 펫 보너스가 빠져 있던 버그를 수정. /api/pets 장착 상태 확인 후 분당 예상 수치 반영.
2. 캐릭터 도감: 펫 도감 추가로 .collection-grid 선택이 펫 도감으로 잘못 연결된 버그 수정.
3. 광장 펫: 메인화면과 동일한 캐릭터 대비 40% 크기, 우측 하단 위치. 펫에 이동/감정 애니메이션이 적용되지 않도록 분리.
4. 개인상점: 이동 영역 크기를 바꾸지 않는 플로팅 패널, 카드형 상품 정렬 및 스크롤 개선. 펫 거래 불가 규칙에 맞춰 펫 판매 등록 UI 제거.
참고: 실제 제초 코인 정산은 기존 서버 updateWeed()에서 10*(캐릭터 보너스+펫 0.3)*풍뎅이 배수로 계산됨. 실제 서버 계정에서 전후 지급 검증은 미실시.
