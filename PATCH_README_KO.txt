겅이마켓 무기 액세서리 연금술 합성 재료 수정 패치

적용: ZIP 내부의 server/index.mjs 및 src/ui/gachaUi.ts 파일을 기존 프로젝트 동일 경로에 덮어쓰기.
기준: 직전 장비/원정대 전투력 표시 패치 UI + 관리자 계정 강화 확률 수정 패치 서버.

레어: 노말 3개 + 강화파편 30개
에픽: 레어 3개 + 강화파편 50개
유니크: 에픽 3개 + 강화파편 150개
레전더리: 유니크 3개 + 강화파편 300개
초월: 레전더리 3개 + 강화파편 500개

직전 등급 3개와 강화파편이 있으면 바로 합성 가능.
기존 '이전 등급 보유' 잠금 및 동일 등급 보유 시 합성 불가 제한 제거.
합성 시 직전 등급 3개 차감, 합성된 등급 1개 추가. 성공률 100%.
재료로 소모되어 장착 중인 등급이 0개가 되면 장착 해제.
관리자 무기 강화 확률 설정 및 다른 게임 기능은 변경하지 않음.
