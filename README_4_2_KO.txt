겅이마켓 4.2 거래 가능 드롭 재화 패치 (staging 우선)
기준: 사용자가 제공한 geong-staging (13).zip
변경 파일 3개를 같은 경로에 덮어쓰고 Railway 서버를 재배포하세요.
- 신규 테이블 gm_tradeable_drops, gm_drop_listings는 서버 시작 시 자동 생성됩니다.
- 패치 이후 토벌장에서 획득한 한계돌파석/겅이복권만 거래 가능 수량으로 증가합니다.
- 기존 보유분과 상점 구매분, 다른 유저에게서 구매한 재화는 거래 불가입니다.
- 판매 등록 시 수량만큼 거래 가능 잔액 예약, 상점 종료/만료 시 예약 해제.
- 판매 시 구매자는 거래 불가 재화를 수령합니다. 개당 최소가격: 돌 3000, 복권 800 다이아.
- 수량과 개당 가격 입력, 판매 완료 우편, 수수료 10% 유지.
- 기타 인벤토리에서 거래 가능/불가 재화를 별도 카드로 표시합니다.
- 서버 JavaScript 문법 검사는 통과. 전체 프로젝트 빌드, 실제 DB, 동시 구매, 만료/취소, 모바일 UI 검증 미완료.
- 운영 서버에 바로 적용하지 말고 staging에서 구매/판매/취소/중복 요청 테스트 필수.
