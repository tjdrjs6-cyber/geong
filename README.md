# 겅이마켓 — 치이카와 캡슐 가챠

2D 카툰 느낌의 캡슐 가챠 게임(겅이마켓)입니다. 아이디·비밀번호로 가입하면 코인과 도감이 서버의 계정에 저장됩니다.

## 규칙

새 계정은 100코인으로 시작합니다. 뽑기는 1회 10코인, 3회 30코인, 5회 50코인, 10회 90코인(할인)입니다. 친구는 21명입니다. 일반 8명(치이카와·하치와레·우사기·모몽가·쿠리만쥬·시사·카니·랏코)은 각 8%, 인어의섬 10명(일반 8명의 인어의섬 버전과 한잎이·두잎이)은 각 3%에 제초 속도 +10%, 희귀 3명(세이렌·시마지로·아노코)은 각 2%에 제초 속도 +20%입니다. 하루 한 번 출석하면 10코인, 새 친구 등록 시 10코인(희귀는 50코인)을 받고 중복은 코인이 없습니다. 뽑기·코인 계산은 서버가 판정합니다.

뽑으면 2D 가챠 기계가 흔들리며 캡슐이 굴러 나오고, 뽑은 친구가 한 명씩 "뿅!" 하고 나타납니다. 도감의 미발견 칸은 회색 "?"이고, 수집한 친구는 "대표로 세우기"로 메인 화면에 세울 수 있습니다. 제초장에서는 친구 한 명이 자동으로 제초해 1시간마다 1코인(보너스 친구는 더 빨리)을 모읍니다.

## 구조

`src/` 게임 클라이언트(DOM + CSS, WebGL 없음), `server/` 계정·가챠 API(Node + MySQL, `server/Dockerfile`), `assets/chars/` 사용자가 제공한 그림에서 잘라낸 21명의 투명 PNG(매니페스트 `assets.lock.json`으로 저장소에서 복원).

## 명령

`pnpm dev`(Preview, 계정 API 자동 실행), `pnpm test`, `pnpm typecheck`, `pnpm build`.

## 캐릭터 능력치

등급·확률·제초 속도·전투력은 아래 "캐릭터 등급 · 확률" 표를 보세요.

토벌장 몬스터 체력은 100이고, 5분마다 전투력만큼 피해를 주며 처치할 때마다 1코인을 받습니다.

## 데코 뽑기 · 데코 도감 · 하우스

- 가챠 화면 아래 **🎀 데코 뽑기** 탭: 1회 20코인 · 3회 60코인 · 5회 100코인 · 10회 180코인.
- 데코 50종이 모두 같은 확률(각 2%)로 나오며, 새 데코를 처음 얻으면 +10코인. 중복 데코는 개수가 늘어 하우스에 여러 개 놓을 수 있습니다.
- **데코 도감**: 못 모은 데코는 회색 ?로 보이고, 모으면 그림이 등록됩니다. 유저 목록에서 다른 유저의 캐릭터 도감 / 데코 도감 탭을 볼 수 있습니다.
- **🏠 하우스**: 텅 빈 공터에 보유한 데코를 꺼내 끌어서 배치하고, 뒤집기·크기 조절·넣기가 가능합니다. 뽑은 캐릭터 1마리도 함께 놓을 수 있으며 배치는 계정에 자동 저장됩니다(최대 60개).

## 출석 체크 · 오늘의 룰렛

- 화면 상단(휴대폰은 왼쪽 위)에 **🎁 출석 체크**(+10코인)와 **🎡 룰렛** 버튼이 있습니다.
- 룰렛은 하루 2회(한국 시간 00:00, 12:00에 각각 초기화). 당첨 확률: 10코인 40% · 20코인 25% · 30코인 17.5% · 50코인 12.5% · 100코인 5%. 결과는 서버에서 정하며, 바퀴 칸 크기도 실제 확률에 맞춰 그렸습니다.
- 하우스 배경은 돌 동굴 아치(가운데 너머 숲) 그림입니다.
- 하우스에는 데코를 최대 10개, 친구(뽑은 캐릭터)를 서로 다른 3명까지 놓을 수 있습니다. 캐릭터는 위치와 상관없이 항상 데코보다 앞(위)에 그려집니다.

## 내 프로필 · 대표 캐릭터 · 우편함

- 화면 위쪽 가운데의 **내 프로필** 버튼(대표 사진 + 닉네임)을 누르면 프로필 창이 열립니다. 로그아웃도 이 창에 있습니다.
- **대표 사진 바꾸기**: 내가 뽑은 친구 중에서 고릅니다. 계정별로 서버에 저장되며, 가챠 무대와 유저 목록 사진에 쓰입니다.
- **우편함**: 받은 편지를 보고, 함께 온 코인을 하나씩 또는 모두 받을 수 있습니다. 안 읽은 편지 수가 프로필 버튼에 빨간 숫자로 표시됩니다.
- **우편 보내기**: 유저 목록에서 유저를 고른 뒤 "편지 보내기". 글은 30자 이내, 코인은 내 보유 코인에서 빠지며 하루(한국 시간) 최대 100코인까지 보낼 수 있습니다. 나에게는 보낼 수 없습니다.
- 캐릭터가 없는 계정의 무대 사진이 흐리게(회색) 보이던 문제를 고쳤습니다.

## 보관함 · 건의함 · 우편함 개선

- **🎒 보관함**: 메뉴(또는 프로필)에서 열고, 캐릭터 / 데코 탭으로 가진 것을 모두 봅니다. 중복 캐릭터는 1개당 3코인, 중복 데코는 1개당 5코인에 팔 수 있습니다(1개 팔기 / 모두 팔기). 원본 1개는 절대 팔리지 않고, 하우스에 놓인 데코도 팔리지 않습니다. 캐릭터 중복 개수는 이번 업데이트 이후 뽑은 것부터 기록됩니다.
- **💌 건의함**: 50자 이내로 건의를 남기면 모두가 볼 수 있습니다(하루 5개까지). 답변(100자 이내)과 삭제는 운영자 계정(운영자겅이)만 할 수 있습니다.
- **📮 우편함**: 받은 편지함 / 보낸 편지함 탭. 편지함마다 최대 10통까지 보관되고, 넘치면 가장 오래된 우편부터 지워집니다(지워지는 우편의 안 받은 코인은 자동으로 받아집니다). 우편마다 🗑 삭제 버튼이 있고, 코인을 안 받은 우편을 지우면 코인을 먼저 받습니다. 우편을 보내면 화면 가운데에 "우편을 보냈어요!" 알림이 뜹니다.
- 메뉴의 "유저 도감"은 **유저 목록**으로 이름을 바꿨습니다.

## 다른 유저 하우스 구경 · 휴대폰 화면 정리

- **유저 목록**에서 유저를 고르면 캐릭터 도감 / 데코 도감 / **🏠 하우스** 탭이 나옵니다. 하우스 탭에서 그 유저가 꾸민 하우스(데코와 친구 배치)를 구경할 수 있어요. 구경만 가능하고 옮기거나 바꿀 수는 없습니다.
- 카카오톡 등 앱 안 브라우저에서 키보드나 주소창 때문에 화면이 위로 밀린 채 남아 맨 윗줄이 주소창 뒤로 숨던 문제를 고쳤습니다(화면이 밀리면 자동으로 제자리로 돌아옵니다).
- 휴대폰에서 메뉴·도감 상자·출석/룰렛 버튼이 캐릭터 무대를 가려 위쪽이 잘려 보이던 문제를 고쳤습니다. 출석·룰렛 버튼을 가로 한 줄로 두고, 캐릭터와 가챠 기계는 화면 높이에 맞춰 크기가 줄어듭니다.

## 하우스 시간당 코인

- 매 정각마다 하우스 안 랜덤 위치에 코인이 하나 떠요. 금액은 1~10코인 중 랜덤입니다.
- 코인을 터치하면 받을 수 있어요. 다음 정각까지 안 받으면 사라지고 새 코인으로 바뀝니다.
- 하우스 위쪽에 "코인이 떴어요! N분 뒤 사라져요" / "다음 코인까지 N분"이 표시됩니다.
- 금액·위치·수령 여부는 서버가 정하므로 한 시간에 한 번만 받을 수 있어요.


## 풍뎅이 · 갑옷씨

- **갑옷씨1·2·3**: 일반 등급, 각 6.06%, 처음 뽑으면 10코인, 전투력 15, 제초 속도 상승 없음.
- **풍뎅이**: 유니크 등급, 0.30%, 처음 뽑으면 50코인, 전투력 1, 제초 속도 상승 없음.
- 풍뎅이 고유 효과: 풍뎅이를 가지고 있으면 제초장에 **풍뎅이 도우미**를 제초하는 친구와 함께 추가로 배치할 수 있어요. 배치해 두는 동안 제초 코인이 **2배**로 모입니다. 배치한 풍뎅이는 토벌장에 보낼 수 없어요(토벌 중인 풍뎅이도 배치할 수 없음).

## 제초장 3명 · 자동 수입

- 제초장에는 친구를 **최대 3명**까지 보낼 수 있어요. 친구마다 각자의 제초 속도로 1시간에 1코인씩 모이고, 풍뎅이 도우미(코인 2배)는 3명 모두에게 적용돼요. 제초 중인 친구를 다시 누르면 쉬게 해요. 제초장에는 '코인 받기' 버튼이 없고, 다음 코인까지 남은 시간과 시간당 제초 코인만 보여요.
- 제초장·토벌장 코인은 화면에 들어가지 않아도 **자동으로** 지갑에 들어와요(접속 시 + 1분마다 정산).
- 보유 코인 아래에 제초장·토벌장으로 얻는 **시간당 코인**(소수점 둘째 자리, 하우스 코인 제외)이 표시돼요.

- 하우스는 방을 크게 보여 주고, 아래 배치 칸에서 데코·친구 탭은 고정되고, 그 아래 고르는 목록만 스크롤돼요.
- 우사기·우사기(인어의섬)는 귀가 길어 작아 보이던 몸 크기를 다른 친구들과 맞췄어요(귀는 틀 밖으로 살짝 나와요).
