기능:
 - 상점 펼침 메뉴 맨 아래 유저 거래소
 - 광장 메뉴 버튼 제거(기존 광장 API/데이터는 안전을 위해 보존)
 - 광장에 상점 개설 없이 판매/구매 가능
 - 겅이복권/한계돌파석/펫박스 등록, 검색, 가격 정렬, 구매, 취소
 - 기존 10% 수수료 및 우편 다이아 지급 방식 유지
 - 거래 가능 드롭품/펫박스만 판매, 재판매 제한 유지
