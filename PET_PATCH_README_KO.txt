겅이마켓 펫 1.0 패치
기준: 광장 개인상점 1.0 패치가 적용된 staging (geong_plaza_shop_1_0_patch.zip).
이 ZIP의 경로 그대로 staging 프로젝트 루트에 덮어쓰세요. 파일 삭제 및 DB 초기화 불필요.

구현:
- 토벌장 몬스터 스테이지 클리어마다 펫박스 0.1% 독립 추첨
- 노말 펫박스 개봉: 꽝 90%, 5종 각 2%
- 펫박스 거래 가능, 미사용/미거래 펫은 1회 거래 가능
- 사용 시 도감 등록, 재판매 불가, 대표 펫 장착/해제
- 장착 1마리 기준 전투력 +10%, 제초속도 +30% (기존 캐릭터 보너스에 가산)
- 광장에서 대표캐릭터 우측 아래 20% 크기로 표시 및 동행
- 개인상점 다이아 거래, 판매 수수료 10%, 상점 24시간 유지
- 사용자 제공 펫 PNG 5종 및 펫박스 PNG 사용

확인할 사항:
- PC/모바일 광장: 펫 탭, 개인상점 탭
- 토벌장 반복 클리어 보상, 펫박스 개봉, 도감/장착
- 펫 거래 및 수수료, 24시간 종료 후 미판매 아이템 잠금 해제
- DB 테이블은 서버 부팅 시 생성됩니다. Railway에서 실제 DB 거래는 별도 테스트 필요.
- 기존 광장/상점 1.0 패치가 적용되지 않은 프로젝트에 단독 적용하면 호환되지 않습니다.
