겅이마켓 3.0 광장 거래 UI 전면 개편 패치

기준: 2.9까지 순서대로 적용된 staging 브랜치
변경 파일만 기존 프로젝트의 동일 경로에 덮어쓰기:
- src/ui/gachaUi.ts
- src/ui/plaza.ts
- src/styles/gacha.css

변경사항:
1. 광장 인사/점프/춤/앉기 버튼 제거 및 기존 이모트 애니메이션 비활성화
2. 거래 광장 UI를 '상품 둘러보기 / 내 상점 관리'로 분리
3. 상품 카드, 판매 가격, 구매 버튼, 내 판매 상품, 판매 등록 관리 UI 개선
4. 펫박스 1000 다이아 미만 등록 시 인게임 메시지로 차단
5. PC/모바일 공통 스타일 적용, 기존 이미지 재사용
6. 기존 API와 거래 서버 로직은 변경하지 않음

주의:
- 새 판매 기능이나 서버 API를 임의로 만들지 않고 기존 /api/plaza/shop, /api/pets/market, /api/pets/list, /api/pets/buy를 사용합니다.
- 실서버에서의 구매/판매 통합 테스트는 수행하지 않았습니다. staging에서 먼저 검증하세요.
- 판매자 닉네임은 서버 응답에 포함될 경우에만 노출하며, 없으면 '다른 유저'로 표시합니다.
- 판매 등록 취소 기능은 기존 API에 대한 검증이 없어 이번 패치에 포함하지 않았습니다.
