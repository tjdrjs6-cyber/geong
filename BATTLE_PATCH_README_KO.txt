겅이마켓 테스트서버 토벌장 패치

README.zip (2026-11-09 업로드) 기준으로 변경된 파일만 포함합니다.
압축 내부 상대경로 그대로 GitHub 저장소 루트에 덮어쓰세요.

변경사항:
- 최대 3명 배치, 왼쪽 삼각형 배치, 뒤쪽 무기 공격 위치
- 1-1 단계 체력 1,000부터 단계별 +1,000, 처치 시 다음 단계 자동 진행
- 각 단계 30분 제한, 시간 초과 시 현재 단계 체력 초기화
- 처치 시 코인 및 강화파편 자동 지급 (1-1~1-5 강화파편 0, 1-6부터 1)
- 기존 토벌장 데이터는 1-1 단계로 초기화, 캐릭터 배치는 유지
- DB 스키마 컬럼 추가 자동 수행

주의:
- 실제 Railway/MySQL 연결 테스트는 수행하지 않았습니다.
- 현재 소스의 node_modules가 없어 TypeScript 빌드 검증을 완료하지 못했습니다.
- 배포 전 테스트 DB 백업을 권장합니다.
