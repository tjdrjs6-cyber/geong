겅이마켓 v2.14 테스트 서버 설치 안내

1. GitHub에서 운영 저장소를 복제하여 별도 테스트 저장소를 생성합니다. 이 ZIP의 파일을 테스트 저장소에 업로드합니다.
2. Railway에서 테스트용 MySQL 데이터베이스를 새로 생성합니다. 운영 DB를 연결하면 안 됩니다.
3. Railway에서 테스트용 서비스를 새로 만들고 테스트 저장소를 연결합니다. 루트 Dockerfile을 사용합니다.
4. 테스트 서비스 Variables에 다음을 설정합니다.
   TEST_SERVER=true
   DATABASE_URL=${{MySQL.MYSQL_URL}}  (테스트 MySQL 서비스의 변수 참조. 실제 서비스 이름에 맞게 선택)
   DB_SSL=false  (Railway 내부 MySQL에서 TLS 미지원 시에만)
5. 테스트 서비스에 별도 도메인을 생성하고 배포 완료 후 /api/health 에서 database:ready 확인.
6. 테스트 사이트에서 아이디 test로 회원가입 후 로그인합니다. 이미 있다면 해당 계정으로 로그인합니다.
7. test 계정은 인증된 API 요청마다 코인(gems), 다이아(diamonds), 강화파편(fragments)이 각각 1,000,000,000으로 다시 채워집니다. 서버측 잔액 보충 방식이며 다른 계정에는 적용되지 않습니다.

주의: 이것은 무한대 숫자가 아닌 요청 시 자동 충전 방식입니다. 한 요청에서 10억을 초과하는 구매는 보장하지 않습니다. 운영 서버에서는 TEST_SERVER를 설정하지 마세요. ADMIN_USERNAME=test 설정은 필요하지 않습니다.
